### 第一场 8:30 AM ｜ 哥伦比亚 vs 加纳

**"哈兰姆球"——当足球变成一堵墙**

加纳主教练奎罗斯（Carlos Queiroz）在本届世界杯上打出了一个让所有对手头疼的战术标签——"Haram-ball"。这个词源自阿拉伯语"haram"（禁止），被媒体用来形容加纳完全放弃进攻的极端防守足球。

小组赛数据说明一切：加纳场均控球率36.1%，在48支晋级球队中排倒数第二。但他们0-0逼平了英格兰——那场比赛英格兰的xG只有1.01。这是一种"我不进球，你也别想"的生存哲学。

**七个模型的内部辩论**

我们先看七个AI分析组件的方向分布：

| 组件 | 哥伦比亚胜 | 平局 | 加纳胜 | 方向 |
|:---|---:|---:|---:|:---|
| DC（统计基础模型） | 55.1% | 23.0% | 21.9% | 🇨🇴 哥伦比亚 |
| Pi-Rating（实力评级） | **74.7%** | 15.7% | 9.6% | 🇨🇴 哥伦比亚 🔥 |
| Elo（积分评级） | 57.4% | 21.3% | 21.3% | 🇨🇴 哥伦比亚 |
| NegBin（比分分布） | 55.7% | 20.8% | 23.5% | 🇨🇴 哥伦比亚 |
| Enhancer（情境增强） | 30.3% | 26.8% | **42.9%** | 🇬🇭 加纳 ❌ |
| Weibull（关联模型） | 32.0% | **53.3%** | 14.7% | 🤝 平局 🔴 跳过 |
| 外部参考（8家共识） | 63.9% | 23.2% | 13.0% | 🇨🇴 哥伦比亚 ✅ |

五个组件指向哥伦比亚，一个指向加纳，一个指向平局（已被系统自动跳过）。

但注意这个分歧的烈度——Pi-Rating给出了74.7%的极端置信度（本届淘汰赛第三高，仅次于阿根廷vs佛得角的78.4%和美国vs波黑的81.5%），而Enhancer却坚决站在加纳一边，给出了42.9%的客场胜率。

**叛逆者Enhancer：为什么它偏要唱反调？**

Enhancer是系统里最有个性的组件——它在淘汰赛阶段的方向错误率高达62%（基于已完成的7场复盘数据）。但42.9%的加纳概率不是随机噪声。它可能捕捉到了几个真实信号：

第一，奎罗斯对哥伦比亚的了解。2019-2020年，奎罗斯正是哥伦比亚国家队的主教练。他了解James Rodríguez的传球习惯、Luis Díaz的突破路线、Daniel Sánchez的防守弱点。知己知彼，从来不是空话。

第二，加纳0-0英格兰不是侥幸。那场比赛加纳的防守组织让欧洲亚军全场xG只有1.01——这是真实发生的证据，不是纸上谈兵。

第三，哥伦比亚对密集防守的历史挣扎。小组赛对民主刚果仅1-0（进球来自定位球），对葡萄牙0-0也无法破门。这支哥伦比亚在攻坚方面没有经受过真正的考验。

但因为Enhancer在淘汰赛仅占10%配置权重（有效权重更低，仅5.8%），它的反向声音被大幅稀释了。

**Weibull的53.3%平局——为什么被"跳过"？**

Weibull Copula模型给出了53.3%的平局概率——本届淘汰赛第二高（仅次于西班牙vs奥地利那场已证明完全错误的64.8%）。

系统自动识别这是"draw_noise"场景——淘汰赛平局基线约22%，53.3%明显脱离现实。正确决策：跳过Weibull，不参与本场融合。

回顾上一轮西班牙3-0奥地利的复盘：Weibull当时给出64.8%平局（Brier=0.945，史上最差单场），因为它过分拟合了"低xG=高平局概率"的模式。这次面对哥伦比亚1.72 vs 加纳1.00的xG预测，Weibull又犯了同样的病。V4.7.0的场景化规则这次救了我们。

**融合链路：从统计基础到最终概率**

```
DC (55.1/23.0/21.9)
  → +Enhancer 10% → (52.4/23.3/24.3)
  → +Elo 22%     → (56.0/21.9/22.1)
  → +Pi 18%      → (67.1/18.4/14.5)  ← Pi极端看多将哥伦比亚拉到67%
  → +NegBin 5%   → (66.6/18.5/14.9)
  → Weibull: 跳过 (draw_noise)
  → +外部参考 31.3% → (66.1/19.1/14.8)
  → 校准器 -5.1pp → **56.99% / 21.67% / 21.34%**
```

注意两个关键转折点：
1. **Pi的18%权重将哥伦比亚从56%拉到了67%**——这是融合链中最大的单步跳跃（+11.1pp）。Pi为本场"最乐观"的组件。
2. **校准器下调了5.1pp**——基于69场WC历史比赛训练的校准器学会了"不信任极端概率"，对67%的热门做了系统性回调。

**Bootstrap重采样发出的警告**

这是本届淘汰赛首次出现"融合基准不在Bootstrap 95%置信区间内"的情况：

```
Bootstrap 500次DC重采样 (仅DC模型):
  哥伦比亚: 29.3% – 47.4%  (中位数 38.4%)
  平局:     30.5% – 38.6%
  加纳:     20.2% – 35.4%

融合最终输出: 57.0% / 21.7% / 21.3%  ← 不在CI内！
```

这意味着什么？DC统计模型的参数不确定性很大。如果只让DC自己重采样500次，它认为哥伦比亚的胜率在29-47%之间——平均只有38%。是Pi（74.7%）和Elo（57.4%）把最终值拉高到了57%。

这不是说融合错了。而是说：**如果Pi和Elo的强烈看多最终被证明是过度自信，DC可能反而是对的。** 这种"融合大幅超越Bootstrap CI"的现象，是我们需要赛后重点验证的信号。

**比分分布：低比分是大概率事件**

三源比分矩阵融合（DC 40% + NegBin+τ 35% + Weibull Copula 25%）给出：

| 排名 | 比分 | 概率 |
|:---|:---:|---:|
| 1 | **1-0 哥伦比亚** | 14.7% |
| 2 | 0-0 | 9.8% |
| 3 | **0-1 加纳** | 9.1% |
| 4 | 2-1 哥伦比亚 | 8.7% |
| 5 | 2-0 哥伦比亚 | 8.7% |

总进球Under 2.5的概率约57%——市场预期也一致指向低比分。哥伦比亚大概率赢球，但很难出现3-0或4-0的碾压。

**决定性变量：前30分钟**

这场比赛的本质是"矛与盾"。哥伦比亚需要在加纳的10人防线前找到缝隙。如果前30分钟破门——加纳被迫放弃"Haram-ball"低位防守，空间打开，比赛走向2-0或3-1。

但如果0-0拖过70分钟——加纳的信心会指数级增长。奎罗斯太清楚怎么打哥伦比亚了。加时赛和点球将从"理论风险"变成"真实威胁"。

**一句话总结**：5/7组件指向哥伦比亚，但Enhancer的叛逆和Bootstrap的警告都在说同一件事——别以市场65%的置信度假定这是轻松过关。哥伦比亚大概率小胜（1-0或2-0），但如果70分钟还是0-0，不要惊讶。这就是"Haram-ball"被设计出来的剧本。

### 第二场 12:00 PM ｜ 阿根廷 vs 佛得角

**梅西 vs 世界杯最小的淘汰赛国家**

这是一场写在纸面上差距最大的比赛。阿根廷——卫冕冠军、FIFA排名第一、Messi金靴状态（6球/3场）、Scaloni治下淘汰赛不败。佛得角——人口最小的淘汰赛参赛国、小组赛0胜（3场平局）、世界杯首秀。

但模型的55.8%阿根廷胜率，远低于外部参考数据85.5%的压倒性共识。30个百分点的差距——这是本届淘汰赛排名第二的模型-市场分歧。

**为什么模型"只"给阿根廷55.8%？**

七个组件中，六个指向阿根廷，只有一个例外：

| 组件 | 阿根廷 | 平局 | 佛得角 | 方向 |
|:---|---:|---:|---:|:---|
| Weibull | **94.5%** | 5.1% | 0.4% | 🇦🇷 阿根廷 (极端) |
| 外部参考（8家） | 85.5% | 12.5% | 5.4% | 🇦🇷 阿根廷 (压倒性) |
| Pi-Rating | 78.4% | 14.2% | 7.3% | 🇦🇷 阿根廷 |
| Elo（差距222分） | 62.8% | 19.8% | 17.4% | 🇦🇷 阿根廷 |
| NegBin | 54.3% | 26.8% | 19.0% | 🇦🇷 阿根廷 |
| DC（统计基础） | 52.6% | 29.4% | 18.0% | 🇦🇷 阿根廷 |
| Enhancer | 32.4% | 13.2% | **54.4%** | 🇨🇻 佛得角 ❌ |

方向共识看似很强——6/7指向阿根廷。但注意概率的分散程度：从Enhancer的32.4%到Weibull的94.5%，跨度高达62个百分点。这种"方向一致但置信度打架"的模式，正是融合链最终只能给出55.8%的根因。

**融合链逐层推演：谁在压低阿根廷？**

```
DC (52.6/29.4/18.0)
  → +Enhancer 10% → (46.5/28.5/25.0)  ← Enhancer将阿根廷拉低6pp
  → +Elo 22%      → (50.2/26.6/23.2)
  → +Pi 18%       → (55.3/24.4/20.3)  ← Pi又拉回来5pp
  → +Weibull 6.4% → (57.8/23.2/19.0)  ← Weibull shadow模式,权重减半
  → +外部参考34.5% → (67.1/19.7/13.2)  ← 外部数据强力拉升(+9.3pp)
  → 校准器 -11.3pp → **55.77% / 20.12% / 24.11%**  ← 本届最大单次下调！
```

融合链上出现了一个戏剧性的"拉锯战"：
1. **Enhancer**将阿根廷从52.6%拉低到46.5%（-6.1pp）
2. **Elo和Pi**又合力拉回到55.3%（+8.8pp）
3. **外部参考数据**以34.5%的权重（市场progressive boost触发）将阿根廷猛拉到67.1%（+11.8pp）
4. **校准器**最后一刀砍掉11.3pp——本届淘汰赛最激进的一次校准下调

**校准器-11.3%：是过度保守还是合理回归？**

这是整篇报告最值得讨论的技术细节。

校准器基于69场世界杯历史比赛训练（ECE=0.052，校准良好）。它学到了一条经验法则："67%的热门经常被爆冷，不要相信极端概率。"所以当融合给出67.1%阿根廷时，校准器自动将其回调到55.8%。

但问题是：阿根廷vs佛得角——Elo差距222分、Messi金靴状态6球/3场、卫冕冠军全胜出线vs小组赛0胜新军——这和校准器训练集中那些"67%热门被爆冷"的比赛，真的是同一类吗？

我们没有简单地把校准器关掉。但我们在报告中标注了这个疑虑。参考先例：美国vs波黑那场，校准器同样下调了11pp，美国仍然2-0完胜。高Elo差距场景下，校准器的"系统性不信任"可能过于保守。

**Weibull Shadow模式的讽刺**

Weibull给出94.5%阿根廷胜——这是系统里最极端的阿根廷看多信号。但因为它"太极端"且缺乏Elo支撑（Elo只有62.8%），系统自动将其置入shadow模式——有效权重从12.8%减半到6.4%。

讽刺的是：外部参考数据85.5%与Weibull的94.5%方向完全一致（都极度看好阿根廷）。如果Weibull不被shadow压制，融合可能会更接近市场的判断。系统的"反极端"保护机制，在这一场可能压错了对象。

**比分矩阵：1-0是最可能的——但市场不这么想**

| 排名 | 比分 | 概率 |
|:---|:---:|---:|
| 1 | **1-0 阿根廷** | 23.5% |
| 2 | **0-1 佛得角** | 12.0% |
| 3 | 3-0 阿根廷 | 10.2% |
| 4 | 0-0 | 9.4% |
| 5 | 2-0 阿根廷 | 8.0% |

模型的三源比分矩阵显示1-0是最可能的比分（23.5%）——这和市场"阿根廷大概率净胜2球+"的定价完全不同。总进球Under 2.5概率52.8%，模型在说：**阿根廷会赢，但不会是大比分碾压。**

佛得角小组赛三场仅失2球，零封西班牙（欧洲冠军）。Vozinha的扑救成功率和全队防守纪律是真实存在的。

**一句话总结**：这是本届淘汰赛方向最明确的比赛。6/7组件+8家外部参考全部指向阿根廷。模型的55.8%被校准器大幅压制（-11.3pp），外部参考的85.5%可能更接近真实概率。真正的悬念不是谁赢——而是1球小胜还是多球大胜。如果Messi首球发生在60分钟前，阿根廷大概率2-0或3-0收工；如果佛得角守住前60分钟，1-0的僵局可能拖入加时。

### 第三场 14:00 PM ｜ 澳大利亚 vs 埃及

**硬币翻转——连AI都说不准的比赛**

这是本届淘汰赛最接近的比赛。不是修辞——是真的接近。

| 指标 | 数值 |
|:---|:---|
| Elo差距 | **0.34分**（几乎持平） |
| 模型内部分歧度 | 0.451（高） |
| 组件方向分布 | 3-3-1 完全分裂 |
| 外部参考方向 | 埃及 38.7%（轻微优势） |
| 模型方向 | 澳大利亚 38.1%（轻微优势） |

Elo差距0.34分是什么概念？系统里Elo评分范围约1300-2000分，0.34分意味着两支球队在数学上完全等价。这是本届淘汰赛最小的Elo差距——比瑞士vs阿尔及利亚的48分还要小两个数量级。

**七个组件打了场"内战"**

| 组件 | 澳大利亚 | 平局 | 埃及 | 方向 |
|:---|---:|---:|---:|:---|
| DC | 35.3% | 39.4% | 25.3% | 🤝 平局 |
| Pi-Rating | 47.1% | 20.5% | 32.5% | 🇦🇺 澳大利亚 |
| Elo（差距0.34） | 38.0% | 24.0% | 38.0% | 🇦🇺 澳大利亚* |
| NegBin | 37.3% | 36.0% | 26.8% | 🇦🇺 澳大利亚 |
| Enhancer | 11.7% | 29.8% | **58.5%** | 🇪🇬 埃及 |
| Weibull ⚠️ | 1.9% | 30.4% | **67.7%** | 🇪🇬 埃及 (shadow) |
| 外部参考（11家） | 28.9% | 32.3% | 38.8% | 🇪🇬 埃及 ✅ |

澳大利亚 3（Pi + Elo + NegBin）vs 埃及 3（Enhancer + Weibull + 外部参考）vs 平局 1（DC）= **3-3-1完全分裂**。

这是你在任何预测系统里能见到的最诚实的答案：**没有人知道谁会赢。**

**关于Salah——最大的单点变量**

Mohamed Salah的左腿腿筋拉伤是这场比赛最大的不确定性。小组赛1球2助攻，参与了埃及6个进球中的5个。最新的训练报告显示他恢复了轻度训练，但主教练Hossam Hassan的表态是："我们期待他明天出场，但不确定是否首发。"

翻译过来就是：Salah大概率替补登场，出场时间预计30-45分钟。

这意味着比赛可能分两个阶段：
- **前60分钟（无Salah）**: Marmoush + Trezeguet领衔，埃及的进攻创造力下降约40%。澳大利亚的5-3-2防守反击体系可能在这个阶段占据上风
- **后30分钟（Salah登场）**: 如果比分仍然胶着，Salah的个人能力将是对澳大利亚防线的终极考验

**Weibull的67.7%埃及——为什么在shadow模式？**

Weibull给出了67.7%埃及胜的极端预测——但同时Elo显示差距仅0.34分。这种"Weibull极端+Elo几乎持平"的组合触发了V4.7.0的场景化shadow规则：Weibull的权重从12.8%减半到6.4%。

事后看，这个决策可能过于保守——因为外部参考数据（11家博彩商，CV<6%）同样偏向埃及（38.8%）。Weibull的方向（偏埃及）与外部共识一致，只是幅度极端。如果它不是被shadow压制，模型最终可能会更接近外部参考的判断。

不过，回顾同一天西班牙vs奥地利——Weibull给出64.8%平局（完全错误），shadow模式又在那一场救了系统。Weibull的极端值就是这样一把双刃剑。

**比分分布：最可能的结果是"无聊"**

| 排名 | 比分 | 概率 |
|:---|:---:|---:|
| 1 | **1-0 澳大利亚** | 22.9% |
| 2 | 0-0 | 19.4% |
| 3 | **0-1 埃及** | 17.7% |
| 4 | 1-1 | 7.3% |
| 5 | 2-0 澳大利亚 | 8.7% |

总进球Under 2.5概率68.7%。BTTS（双方进球）概率仅21.8%。至少一方零封概率78.2%。

模型在说：这场比赛大概率是一方1-0小胜，或者0-0拖入加时。别指望对攻大战。

**一句话总结**：这是本届淘汰赛最接近的"硬币翻转"比赛。两支从未赢得世界杯淘汰赛胜利的球队，实力极度接近（Elo仅差0.34分），七个模型组件3-3-1完全分裂，外部参考与模型方向相反。**任何一方1球小胜或拖入加时都是合理结果。** 模型微弱的澳大利亚偏好主要来自Pi-Rating的独立判断+校准器的分布平移，真正的X因子是Salah的出场时间和身体状态。

### 升级一：三源比分矩阵 —— 从"独裁"到"议会制"

**旧世界的秩序**

在V4.7.0之前，比分预测是这样工作的：

```
只有DC（Dixon-Coles）模型产出完整比分矩阵
  → 其他6个组件（Enhancer/Elo/Pi/NegBin/Weibull/外部参考）
  → 只参与"谁赢"的概率融合，完全不碰比分分布
  → 最后的比分校准器只是按最终胜/平/负概率机械缩放
```

这带来一个问题：**如果DC的比分形态是错的，整个比分预测就全错。** 没有制衡，没有第二条意见。

实际数据证实了这个担忧——在19场已有赛后复盘数据的比赛中，精确比分命中率仅5.3%（1/19），淘汰赛命中率0%（0/7）。

**新世界的三权分立**

V4.7.0-alpha引入三源比分矩阵融合：

```
DC (Poisson+τ, 40%权重)
  ↓
NegBin+τ (负二项分布+依赖修正, 35%权重)  ← 全新加入
  ↓
Weibull Copula (25%权重)                 ← 首次暴露比分矩阵
  ↓
三源加权平均 → 约束校准（对齐最终胜/平/负概率）
```

NegBin的加入有坚实的学术支撑——2024年发表在顶刊*JRSS-C*上的Michels et al.论文证明：负二项分布边缘+τ依赖修正，数学上等价于Sarmanov族的最优形式。它比Poisson更好地处理"过离散"问题（比分方差大于均值），而这恰恰是世界杯淘汰赛的特征。

Weibull Copula是另一个故事。Boshnakov et al.（2017, *IJF*）证明Weibull计数模型对足球比分的拟合优度显著优于Poisson（p>0.10 vs p<0.002）。但之前我们只用它输出胜/平/负三个概率——V4.7.0终于把它内部的完整比分分布矩阵暴露了出来。

**参数最优化的背后**

通过walk-forward网格搜索（在已完成的世界杯比赛上回测），我们找到了当前阶段的最优参数：

| 参数 | 旧值 | 新值 | 含义 |
|:---|:---|:---|:---|
| xG校准因子 | 1.0 | **1.20** | 将原始xG放大20%以匹配WC实际进球率 |
| NegBin r | 3.5 | **8.0** | 过离散程度——r越大越接近Poisson（方差越小） |
| τ (依赖参数) | 0.0 | **-0.30** | Dixon-Coles低比分依赖修正强度 |

τ=-0.30是一个非常有趣的发现。它意味着WC淘汰赛中，低比分之间的依赖关系比俱乐部比赛更强——0-0和1-0之间的"切换"概率比随机假设更低。换句话说，**淘汰赛一旦进入低比分节奏，就很难跳到高比分。** 这符合我们的直觉——淘汰赛球队趋于保守。

预期效果：精确命中率从5.3%提升到10-15%，淘汰赛命中率从0%突破到≥15%。这是我们在R16窗口期重点验证的指标。

### 升级二：外部数据融入——从"一刀切"到"因材施教"

这是继比利时vs塞内加尔灾难后的最核心修复。

**旧世界的两大致命缺陷**

缺陷一：**15个百分点的硬悬崖。**

旧逻辑是：如果模型预测和外部参考数据的分歧≤15pp → 外部数据完全不融入（0%权重）。如果分歧>15pp → 外部数据以最高30%权重融入。

这意味着什么？模型-外部共识分歧14.4pp → 外部数据权重0%。分歧15.1pp → 外部数据权重34.5%。这种"非0即1"的开关，让大量有价值的外部信息被一刀切排除了。

最典型的受害者：澳大利亚vs埃及。11家博彩商高度一致（CV<6%）指向埃及，与模型分歧14pp——差了1个百分点，外部数据完全没有融入。但方向是**完全相反**的——模型说澳大利亚占优，外部共识说埃及占优。这在决策层面是巨大的差异。

缺陷二：**Web搜索共识数据被完全忽视。**

系统有四层数据获取链：API实时（1-2家博彩商）→ Web搜索缓存（8-12家博彩商）→ 手工赔率文件。但旧代码的逻辑是"API如果能返回数据（哪怕只有1家），就不查Web缓存"。

这意味着——当API返回10Bet一家数据时，系统就用这一家的赔率计算"市场共识"。而此时我们手工从Web上搜到了8-12家博彩商的共识数据，写进了报告里，但**从未真正输入到融合计算中**。

哥伦比亚vs加纳就是典型案例：API只有10Bet一家（赔率有时偏极端），Web搜索显示8家博彩商共识指向哥伦比亚约65%。但旧系统只用10Bet的66.4%来计算分歧——如果10Bet有偏差，整个分歧计算就是错的。

**新世界的渐进式门槛**

V4.7.0-alpha做了三件事：

**第一，Web共识不再是"备胎"而是"交叉验证"。** API返回后，系统会**无条件**查询Web缓存。如果Web有≥3家博彩商，优先用Web共识数据（或与API数据合并）。

**第二，分歧阈值按数据质量分级，不再是15pp一刀切。**

| 数据质量 | 博彩商数 | 变异系数 | 有效门槛 | 示例 |
|:---|:---|:---|:---|:---|
| 🔴 低质量 | 1-2家 | 无可靠CV | 15pp | 仅API单源 |
| 🟡 中等质量 | 3-5家 | <10% | 13pp | Web有几家 |
| 🟢 高共识 | ≥6家 | <6% | **10pp** | 主流比赛 |

**第三，新增"部分融入区间"。** 在有效门槛和15pp之间的区域，不是0%也不是100%，而是线性渐变。

三场比赛的受益：

| 比赛 | 博彩商 | 分歧 | 旧结果 | 新结果 |
|:---|:---|:---|:---|:---|
| 阿根廷vs佛得角 | 8家, CV<9% | 30pp | ✅ 融入34.5% | ✅ 融入34.5%（不变） |
| 澳大利亚vs埃及 | 11家, CV<6% | 14pp | ❌ 不融入 | ✅ 融入32.2% |
| 哥伦比亚vs加纳 | 8家, CV<8% | 12pp | ❌ 不融入 | ✅ 融入31.3% |

后两场在旧系统里外部数据都是0%权重，现在以约32%的权重正常融入。这意味着模型不再是"闭门造车"——当11家博彩商一致说埃及占优时，模型至少会部分参考这个外生信号。

### 升级三：11个Bug修复——建立"安全防线"

系统在快速迭代中积累了一批隐藏Bug。V4.7.0-alpha做了一次地毯式排查，修复了最重要的11个问题。以下挑四个最精彩的"病例"讲。

**病例一：KO Draw Guard的静默消失**

这是最危险的一类Bug——代码不报错，但功能静默丢失了。

KO Draw Guard是一个专门针对淘汰赛平局低估设计的保护机制。当融合输出的平局概率低于22%时，它会自动追加风险标签。但在`predict_sync()`这个代码路径中，风险标签的列表变量（`risk_tags`）在赋值之前就被使用了——Python会抛出`UnboundLocalError`。

问题是，这段代码外层被`try/except`包裹，异常被静默捕获了。**结果：所有通过这个路径的淘汰赛预测，KO Draw Guard从未真正工作过。**

修复很简单——在函数开头初始化`risk_tags = []`。但发现它需要逐行审查整个融合链。

**病例二：赛后复盘绕过了学习权重控制**

这是五重根因定位后发现的"漏网之鱼"。

系统对每场赛后复盘都会计算一个`learning_weight`（0-1之间），决定这场比赛能多大程度上参与自进化学习。红牌比赛只记录不调参（LW<0.30），xG异常比赛降权，正常预测全权参与。

但是`run_postmatch_complete.py`这个最常用的复盘脚本里，调用学习引擎时——**没有传入`learning_weight`参数**。这意味着不管过程评估得出什么结论，学习引擎都默认按`learning_weight=1.0`处理——等同于"这场比赛完美可信，全力学习"。

想象一下瑞士vs阿尔及利亚那场——过程标签是PROCESS_CONTRADICTED（xG方向完全反了），learning_weight被正确地设为0.255（record_only，不参与学习）。但因为脚本没有传这个参数，**学习引擎拿到的是1.0**。

修复后，过去三天三场复盘（瑞士vs阿尔及利亚、西班牙vs奥地利、葡萄牙vs克罗地亚）的learning_weight被正确写入数据库：0.255、0.68、0.85——分别对应record_only、diagnostic、full三个层级。

**病例三：版本号比git HEAD落后两个版本**

`version.py`里写的是`V4.5.0-beta`。但git HEAD的commit message是`V4.6.0-alpha`，而实际代码功能已经是`V4.7.0-alpha`。

这看起来是个小问题——改一行字符串而已。但它导致了一个系统性问题：报告里的版本号是手写的（V4.7.0-alpha），DB里的权重配置标签是旧的（V4.5.0），代码声称的版本又是另一个（V4.5.0-beta）。三套版本号各自为政，让事后审计几乎无法追溯"这场比赛到底用了哪个版本的逻辑"。

V4.7.0做了全局版本同步：`version.py`、README、CHANGELOG、两篇架构文档、权重配置标签——所有地方统一为`V4.7.0-alpha`。还补打了git tag `v4.7.0-alpha`。

**病例四：Weibull的两极分裂——同一天，一个史上最佳，一个史上最差**

这不是一个要修的Bug，而是一个值得讲述的故事。

7月3日的两场比赛：

- **葡萄牙vs克罗地亚**: Weibull给出葡萄牙84.8%，Brier=0.042——**系统运行以来所有比赛中的单场最佳表现**。融合的Brier是0.334，Weibull的误差只有融合的1/8。Pi也不遑多让（Brier=0.125），两者都是葡萄牙的坚定支持者，但各自在融合中只占6.4%和18%的有效权重——被严重低估。

- **西班牙vs奥地利**: Weibull给出64.8%平局，Brier=0.945——**系统运行以来最差的单场表现**。完全、彻底、灾难性地错误。西班牙3-0碾压。而Pi（Brier=0.252）和Elo（Brier=0.270）都远超融合（Brier=0.318）。

同一个模型，同一天，天堂和地狱。

这件事教给我们的是：**Weibull在淘汰赛阶段的"信号质量"方差极大——它不是不可用，而是需要更聪明的使用方式。** 简单地在所有比赛给Weibull固定10%权重（或固定shadow模式），等于同时浪费了它最好的一面和容忍了它最差的一面。

更智能的方向——也许在R16窗口期实现——是让Weibull的权重随场景动态调整：当它给出的极端方向与Elo和外部共识一致时（如葡萄牙场），提升权重；当它与Elo严重冲突且给出极端平局时（如西班牙场），降低甚至归零。

### 过去三天，三场复盘教给我们的

**瑞士 2-0 阿尔及利亚 —— Pi单枪匹马救场**

这是本届最极端的分裂案例。**5个组件预测阿尔及利亚胜，只有Pi和Weibull预测瑞士胜。** 最终瑞士2-0完胜。

但我们不能把这个结果当作"模型成功"的证据。过程评估显示xG完全反转：预测阿尔及利亚1.26 > 瑞士0.91，实际瑞士2.52 > 阿尔及利亚0.73。xG MAE=1.07，远超0.75的警戒线。

失败类型：**LUCKY_RESULT**（侥幸正确）。Learning Weight：0.255（record_only——不参与任何学习）。

关键发现：当Elo逆转（阿尔及利亚Elo高于瑞士48分）引导所有统计组件走向错误方向时，**Pi的独立信号是模型的最后防火墙。** 没有Pi的79.1%瑞士概率（18%有效权重），融合会被5个错误组件拖向阿尔及利亚。

**西班牙 3-0 奥地利 —— Weibull的史诗级误判**

5/7组件方向正确。Pi和Elo的Brier（0.252/0.270）远优于融合（0.318）。但Weibull 64.8%平局（Brier=0.945）把融合拖低了。

失败类型：**WEIBULL_EXTREME_ERROR**。过程标签：PROCESS_SUPPORTED（xG方向正确，西班牙2.65 vs 奥地利0.32完全碾压）。Learning Weight：0.68（diagnostic——可诊断但不触发调权）。

关键发现：外部参考数据（西班牙70.4%，Brier=0.126）是本场的"正确答案"——如果市场信息以更高权重建模，Brier能从0.318降到0.20以下。这也是V4.7.0推动外部数据融入升级的直接动力。

**葡萄牙 2-1 克罗地亚 —— 最好的比赛，最被浪费的信号**

6/7组件方向正确（86%，淘汰赛第二高）。但真正的故事是Weibull和Pi。

Weibull Brier=0.042（史上最佳），Pi Brier=0.125——两者在融合中有效权重分别仅6.4%和18%。融合Brier=0.334，是Weibull的8倍。

失败类型：**GOOD_PREDICTION**。Learning Weight：0.85（full tier——可触发权重提案，但因为是正确预测，边际信息量不如错误预测大，建议不主动调权）。

关键发现：**Weibull和Pi在淘汰赛中严重被低估。** 如果两个组件的KO权重适当提升（Weibull 6.4%→12-15%，Pi 18%→25%），这场比赛以及未来类似比赛的Brier会大幅下降。这是R16窗口期的优先调权方向。
